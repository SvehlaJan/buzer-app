# Decisions

Use this directory for durable architecture and product decisions. A decision document is needed when work changes the approved design, adds a dependency, changes storage/API shape, or resolves ambiguity that future agents will otherwise rediscover.

Filename format:

```text
YYYY-MM-DD-short-decision-title.md
```

Template:

```markdown
# Decision: <Title>

Date: YYYY-MM-DD
Status: Accepted

## Context

What problem or ambiguity forced this decision?

## Decision

What did we choose?

## Consequences

What becomes easier, harder, or intentionally deferred?

## Alternatives Considered

- Alternative and why it was not chosen.
```
